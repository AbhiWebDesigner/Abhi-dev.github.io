## ✨ Overview

**ABHI.DEV** is a responsive, single-page developer portfolio with a dark cyber-inspired visual style. It presents Abhi as an AI developer, web developer, and UI designer through a focused hero section, project showcase, skills section, and contact area.

The site is intentionally lightweight and built with vanilla web technologies—no frameworks, build tools, or external dependencies required.

## 🚀 Features

- Futuristic dark interface with cyan-to-purple gradient accents
- Single-page navigation with smooth scrolling
- Hero section focused on AI-powered experiences
- Project cards for AI bots and automation work
- Skills showcase for frontend and backend technologies
- Scroll-triggered fade-in animations
- Glassmorphism-inspired cards and hover effects
- Mobile-friendly viewport configuration
- Simple, fast static-site architecture

## 🛠️ Tech Stack

## 💻 Run Locally

Because this is a static website, you can open `index.html` directly in a browser. For a better local development experience, use a local server:

```bash
git clone https://github.com/AbhiWebDesigner/Abhi-dev.github.io.git
cd Abhi-dev.github.io

# Optional: start a local server with Python
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## 🎨 Customize the Portfolio

1. Update the title, hero copy, projects, skills, and contact details in `index.html`.
2. Replace the placeholder project buttons with real live-demo and repository links.
3. Adjust the color system in `css/styles.css` through the `--bg`, `--primary`, and `--accent` variables.
4. Add a profile image, social links, or new portfolio sections as your work grows.

## 🌐 Deployment

This repository is configured as a GitHub Pages project site. To publish updates:

1. Push changes to the `main` branch.
2. Open **Settings → Pages** in the repository.
3. Select **Deploy from a branch**, choose `main`, and select the root folder.
4. Save and open the generated Pages URL.
